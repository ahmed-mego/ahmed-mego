### 🚀 What I'm Working On

Currently working on **embedded and robotic systems**, with a focus on developing reliable low-level controllers for robotic manipulators.

One of my main projects is a **distributed control architecture for a 6-DOF KUKA-inspired robotic arm**, where STM32-based joint controllers communicate with a high-level controller through CAN/FDCAN.

The low-level firmware includes:

* ⚡ Hardware-based pulse train generation
* 🔄 Quadrature encoder interfacing
* 📡 CAN/FDCAN communication
* 🧵 Real-time firmware architecture
* 📦 Motion-command FIFO buffering
* 🎯 Pulse-error accumulation for improved positional accuracy
* 🛡️ Hardware-driven safety handling
